Network Engine

Fitur jaringan lanjutan terpisah dari DNS, dengan opsi pemulihan.

⌁ Preset TCP

Preset ini mengubah TCP sysctl yang di-allowlist dan didukung kernel. Klik preset merupakan opt-in eksplisit. Preset tidak mengubah DNS, firewall, APN atau radio.

TCP enabled—Algoritma tersedia—Algoritma aktif—

◉ Private DNS

Pemilih provider DNS bergaya PingPimp, ditambah hostname kustom. Android Private DNS diterapkan secara global; opsi Wi-Fi/mobile terpisah per jaringan tidak diasumsikan tersedia pada ROM ini.

Mode—Hostname aktif—
Jika internet gagal setelah ganti provider, tekan Automatic atau Restore DNS. Provider hanya mengubah Android Private DNS; ini bukan jaminan ping turun.

↗ DSCP marking

Menandai paket outbound pada port yang dipilih. Jaringan/operator dapat mengabaikan DSCP; ini bukan jaminan ping lebih rendah. Default OFF.

Status runtime—
Menggunakan chain milik HanniBomb sendiri. Jika target iptables tidak tersedia, fitur menolak aktivasi.

⌁ Traffic shaping (tc)

Opsional dan dibatasi: hanya mengganti root noqueue agar qdisc vendor yang parameternya tak diketahui tidak tertimpa. Pemulihan hanya dicoba bila TBF HanniBomb masih terlihat.

Default interface—Root qdisc—Konfigurasi—Status runtime—

⌁ Latency test

Empat paket ICMP diagnostik. Beberapa server atau jaringan seluler bisa memblokir ICMP.

⌁ Wi-Fi scan throttle

Membatasi pemindaian Wi-Fi latar belakang Android. Bisa memengaruhi pencarian lokasi atau discovery perangkat.

Output & activity

Hasil perintah root terakhir, termasuk kegagalan dari ROM/kernel.

◉ Display Color Enhancer

Kontrol utama mengikuti metode AyundaRisuColorEnhancer: panggilan SurfaceFlinger 1022 f dengan skala 1.0–2.0, bukan persentase 0–100. Mulai dari 1.3–1.5; 2.0 bisa membuat warna terlalu pekat. Perintah ini bergantung pada dukungan ROM/SurfaceFlinger.

1.5
